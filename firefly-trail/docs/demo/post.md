@_月云 你说想玩「那种治愈的2D跑图游戏」，还说很喜欢那种美术风格——我就真的做了一个 ♡
它叫《萤火小径 Firefly Trail》。

从清晨的花田出发，慢慢走到夜晚的海边：
🌼花田 → 🌸樱花坡 → 💧镜湖 → 🍄黄昏森林 → ❄️雪原 → 🌊星海岸

一路收集漂浮的微光，凑齐三个就能点亮一盏石灯笼，还会收到一张小明信片；
路上会遇到小猫、青蛙和狐狸，走近了它们会和你说话，还可以摸摸它们；
走累了就坐下来看一会儿雪，主角会自己想一些小事情。
五盏灯都亮了，海边的灯塔就会为你亮起来。

没有分数，没有倒计时，也不会失败，慢慢走就好。
画面和音乐全部是代码写出来的，没用一张图片素材。

手机、电脑浏览器打开就能玩，中文 / English 都有～
试玩链接在评论区置顶 👇
